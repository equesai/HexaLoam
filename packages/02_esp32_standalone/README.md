# HexaLoam ESP32 Standalone Edition

## Included Files & Folders

- `firmware/esp32/actuator-slave/`
- `firmware/shared/hexaloam_joint_map.h`
- `electronics/wiring/02_esp32_dual_pca9685.pdf`
- `electronics/connection-tables/02_esp32_dual_pca9685.md`
- `control/calibration/`

## Quickstart
1. Verify wiring against `electronics/wiring/` and `electronics/power/POWER_ENGINEERING.md`.
2. Calibrate servos at 1500 us neutral before assembling horns (`control/calibration/README.md`).
3. Follow `testing/electrical/` through `testing/locomotion/` progressively.
