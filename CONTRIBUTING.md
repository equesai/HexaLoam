# Contributing to HexaLoam

The platform is intended for modification. A useful contribution can be as small as a verified print dimension or as substantial as a reproducible gait experiment. Choose an item from the [development roadmap](docs/development-roadmap.md) and describe the configuration you used.

| Contribution | Evidence to include |
| --- | --- |
| Print or mounting improvement | Editable part and export, part revision, fit dimensions, printer/material/profile, and a photograph or measurement of the result |
| Unity or Unreal import | Editor and importer versions, mesh names, scale and axes, one measured dimension, screenshot, and steps to reproduce |
| Simscape or controls result | Source revision, joint map and frame conventions, assumptions, commands, expected and observed motion, and a small trace or plot |
| Agricultural sensor study | Mount pose, sensor settings, terrain, ground truth and timestamps, plus a description of where the method failed |

Start an [issue](https://github.com/equesai/HexaLoam/issues) for a design proposal or missing dependency. For a pull request, keep the editable source with the change and explain how a reviewer can reproduce it. Label values as measured, simulated, manufacturer-specified or assumed. Keep generated editor caches and personal paths out of the submission.

Identify the author, source and applicable permissions for any third-party material you propose distributing. HexaLoam is released under the [MIT License](LICENSE); contributions are accepted under the same license.
